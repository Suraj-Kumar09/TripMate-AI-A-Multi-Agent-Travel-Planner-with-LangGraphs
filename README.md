## 📌 Overview

**TripMate AI** is an end-to-end **Multi-Agent AI Travel Planner** designed to automate the travel-planning process.

Instead of manually searching across multiple websites for flights, hotels, sightseeing options, and itinerary ideas, users can simply describe their requirements in natural language.

### Example

```text
Plan a complete 7 days USA trip from India including flights,
hotels and sightseeing under ₹2 lakhs.
````

TripMate AI processes the request through a **LangGraph-based multi-agent workflow** and produces a structured travel plan containing:

* ✈️ Flight information
* 🏨 Hotel suggestions
* 🗺️ Day-by-day itinerary
* 💰 Budget-aware recommendations
* 📋 Final consolidated travel plan

---

# 🚀 Key Features

### ✈️ Flight Research Agent

Uses **AviationStack API** to retrieve flight-related information based on the user's travel request.

* Processes the travel query
* Searches flight information
* Extracts relevant flight data
* Passes results to downstream agents

### 🏨 Hotel Research Agent

Uses **Tavily Search API** for web-based hotel research.

* Hotels
* Accommodation options
* Locations
* Hotel information
* Relevant travel sources

### 🧠 AI Itinerary Agent

Uses a **Groq-hosted LLM** through LangChain to generate a practical day-by-day itinerary based on:

* Destination
* Duration
* Budget
* Travel preferences
* Flights
* Accommodation

### 🎯 Final Response Agent

Consolidates the information generated by previous agents into:

1. Trip Summary
2. Flight Information
3. Hotel Suggestions
4. Day-by-Day Itinerary
5. Estimated Budget
6. Final Recommendations

### 🌐 FastAPI Web Application

The project provides a web interface built with:

* FastAPI
* Jinja2
* HTML
* CSS
* JavaScript

### 📄 Copy & PDF Export

Users can:

* Copy the generated travel plan
* Download the travel plan as PDF

Markdown is rendered using **Marked.js** and PDF generation is handled using **html2pdf.js**.

## 🧠 LangGraph

Used for building and orchestrating the multi-agent workflow.

The workflow connects individual agents using explicit graph edges:

```python
graph.add_edge(START, "flight_agent")
graph.add_edge("flight_agent", "hotel_agent")
graph.add_edge("hotel_agent", "itinerary_agent")
graph.add_edge("itinerary_agent", "final_agent")
graph.add_edge("final_agent", END)
```
